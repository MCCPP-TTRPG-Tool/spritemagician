# Session Log - 2026-03-04 - Session 002

## Goal
Pivot 3D work to local-first rigging foundation: upload 3D model, view in three.js, and place humanoid rig markers (AccuRig-style scaffold) without relying on RunPod.

## Work Completed
- Removed immediate 3D RunPod coupling from generation endpoint:
  - Updated `src/routes/api/3d/generate/+server.js` to return local-first guidance instead of submitting upstream jobs.
  - Kept auth, rate limiting, idempotency, and usage tracking intact.
- Added server route for 3D model upload:
  - New `src/routes/api/upload-3d-model/+server.js`.
  - Accepts data URL model payloads (`.glb`, `.gltf`, `.fbx`, `.obj`) with size limit and validation.
  - Uploads to Firebase Storage via Admin SDK and returns a signed tokenized media URL.
- Upgraded left 3D panel model ingestion flow:
  - Updated `src/lib/components/ModelGeneration3DPanel.svelte`.
  - Added direct model upload button + file picker and upload handling.
  - On successful upload, writes URL to `projectStore.threeDModelUrl` and routes to rigging view.
- Replaced preview-only model-viewer with an actual three.js rigging workspace:
  - Updated `src/lib/components/RigAnimation3DPanel.svelte`.
  - Uses three.js scene + camera + orbit controls + loaders for:
    - `.glb/.gltf` via `GLTFLoader`
    - `.fbx` via `FBXLoader`
    - `.obj` via `OBJLoader`
  - Added click-to-place marker workflow with local-space coordinates for humanoid markers:
    - pelvis, spine, neck, head
    - shoulders/elbows/wrists (L/R)
    - hips/knees/ankles (L/R)
  - Added coverage status, clear markers, and `Save RigSpec` action.
- Extended project store for rigging persistence:
  - Updated `src/lib/stores/project.js` with `threeDRigSpec` persisted in local project state.
