# Session 094 - Genesis Model Selector (Nano Banana / GPT / DALL-E)

Date: 2026-02-24

## Objective
- Add a quick model picker in Genesis so users can choose image generation model per request.

## Changes Made

### Frontend
- `src/lib/components/DesignPanel.svelte`
  - Added Genesis model selector UI in Genesis mode.
  - New options:
    - `Nano Banana (Gemini)`
    - `GPT-4 Image (OpenAI)`
    - `DALL·E (OpenAI)`
  - `generateGenesis()` now sends `generationModel` to `/api/generate-sprite`.

- `src/lib/stores/design.js`
  - Added persisted `genesisModel` state (`nano_banana` default).
  - Included `genesisModel` in saved conversation snapshots and restore path.

### Backend
- `src/routes/api/generate-sprite/+server.js`
  - Added `generationModel` request handling and model routing:
    - `nano_banana` -> Gemini (`gemini-2.5-flash-image`) existing path
    - `gpt4` -> OpenAI `gpt-image-1`
    - `dalle` -> OpenAI `dall-e-3`
  - Added OpenAI image generation helper (`/v1/images/generations`) with `b64_json` response.
  - Added clearer key errors:
    - Gemini path requires `GEMINI_API_KEY`
    - OpenAI path requires `OPENAI_API_KEY`
  - Current constraint:
    - Reference image lock is supported on Nano Banana path.
    - OpenAI routes currently return explicit error if reference image is provided.
  - Usage ledger provider metadata now reflects selected provider/model.
