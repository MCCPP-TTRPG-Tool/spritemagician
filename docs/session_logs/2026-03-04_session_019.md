# Session Log - 2026-03-04 - Session 019

## Goal
Fix blocked viewport model loads caused by browser CORS failures against Firebase storage, which prevented reliable rigging save/submit workflow.

## Work Completed
- Added new endpoint `src/routes/api/3d/model-proxy/+server.js`:
  - authenticated, rate-limited proxy for remote model fetch.
  - validates URL protocol and host allowlist (`firebasestorage.googleapis.com`, `storage.googleapis.com`).
  - streams model bytes back from same origin with preserved content type.
- Updated `src/lib/components/RigAnimation3DPanel.svelte`:
  - added `toViewportFetchUrl(...)` helper.
  - remote model URLs are now automatically routed through `/api/3d/model-proxy` before passing to three.js loaders.
  - blob/data and same-origin URLs bypass proxy.

## Result
- Firebase model URLs can now be loaded in the viewport without client-side CORS failures.
- Rigging flow is no longer blocked by browser fetch errors while loading model geometry.
