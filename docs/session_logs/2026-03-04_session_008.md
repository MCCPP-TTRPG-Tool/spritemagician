# Session Log - 2026-03-04 - Session 008

## Goal
Make rig jobs Blender-ready with a concrete payload contract and a runnable headless Blender rigging script.

## Work Completed
- Added Blender rig payload builder:
  - New `src/lib/server/blenderRigPayload.js`.
  - Defines canonical humanoid bone hierarchy and `buildBlenderRigPayload(...)`.
  - Payload includes:
    - input model URL + format hint
    - marker map
    - rig options
    - normalization directives (axis/ground/center/target height)
    - deterministic output paths for `.blend` and preview `.glb`.
- Upgraded rig job creation:
  - Updated `src/routes/api/3d/rig/+server.js`.
  - Rig jobs now persist `blenderPayload` inside Firestore job docs.
  - API response now includes `blenderSpecVersion`.
  - Accepts optional `modelPreflight` to inform normalization defaults.
- Wired UI submit to include preflight:
  - Updated `src/lib/components/ModelGeneration3DPanel.svelte`.
  - `Run Rigging` now sends `modelPreflight` with marker rig request.
- Added payload fetch endpoint:
  - New `src/routes/api/3d/rig-blender-payload/+server.js`.
  - Returns Blender payload for authenticated owner by `jobId`.
- Added headless Blender runner script:
  - New `runpod/blender_rig_from_markers.py`.
  - Script flow:
    1. load payload JSON
    2. download source model
    3. import model (`.glb/.gltf/.fbx/.obj`)
    4. normalize (ground, center, target height)
    5. build armature from marker hierarchy
    6. parent meshes with automatic weights
    7. save `rigged.blend`
    8. export preview `rig_preview.glb`
