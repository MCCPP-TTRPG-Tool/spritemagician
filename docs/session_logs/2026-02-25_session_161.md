# Session 161 - Jobs Persistence Fix for Design/Edit Completions

Date: 2026-02-25

## Objective
- Fix issue where completed Design/Edit jobs were not appearing in Jobs history and were lost on refresh.

## Root Cause
- `JobsPanel` renders completed items from `completedJobs` store (IndexedDB-backed).
- `DesignPanel` and `EditPanel` were only calling `jobQueue.completeJob(...)` and never writing completed image jobs to `completedJobs`.
- `jobQueue` itself is in-memory, so refresh cleared those completed records.

## Work Completed
- Updated `src/lib/components/DesignPanel.svelte`:
  - Added `completedJobs` import.
  - On successful Genesis generation, now calls `completedJobs.addSprite(...)` before marking queue job complete.
- Updated `src/lib/components/EditPanel.svelte`:
  - Added `completedJobs` import.
  - On successful Edit/Expand result, now calls `completedJobs.addSprite(...)` before downstream actions.

## Outcome
- Completed Design/Edit image jobs are now logged in Jobs completed history.
- Completed entries persist across refresh because they are now saved to IndexedDB-backed `completedJobs`.
